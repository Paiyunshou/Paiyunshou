## 🆕 最近在做：非贸备案扣税多维表流程系统

把非居民供应商名录、合同备案、扣税三层多维表串成一条流程：业务提交、财务建明细、税务算税扣款、资金安排支付，十处自动通知与状态回写替代人工催办。核心是涉税判断与计税依据还原——非居民承担 ÷(1+增值税率)，中方承担 ÷(1−所得税率)，再按税率求税。

📑 [**slides**](https://github.com/Paiyunshou/slides)：三页演示 deck 收在这个合集里，一屏归档、逐页翻页。

接下来：把这套口径推到其他税种，并把思源笔记里的财税知识库接成同一条工作流。
